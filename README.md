# ChordPro Maker

ทำไฟล์คอร์ด/เนื้อร้องสำหรับ **SongBookPro**
ไฟล์เดียว เปิดในเบราว์เซอร์ ไม่ต้องติดตั้งอะไร

*Make ChordPro files for **SongBookPro**. One HTML file, runs in the browser, no install.*

**▶ ใช้งานได้ที่ https://atthakornpm.github.io/chordpro-maker/**

---

## ใช้ยังไง · How to use

1. ใส่ **ชื่อเพลง** แล้วกด **ค้นหาคอร์ด** — ถ้าเพลงนั้นมีในฐานข้อมูล จะได้คอร์ดกับเนื้อร้อง
   จัดรูปแบบเสร็จทันที เปลี่ยนคีย์ได้ 14 คีย์ ไม่ต้องใช้ AI ไม่เสียเงิน
2. **ถ้าหาไม่เจอ** วางใบคอร์ดของคุณเองลงในกล่องบน แล้วกด **จัดรูปแบบ**
   หรือให้ AI ช่วยเกลาก่อนก็ได้
3. กด **บันทึก .txt** หรือ **ส่งออก .sbp** แล้วเปิดไฟล์นั้นด้วย SongBookPro

ไฟล์ `.sbp` นำเข้า SongBookPro ได้ตรงๆ ไม่ต้องแปลงอีกชั้น

---

## มีอะไรบ้าง · What it does

| | |
|---|---|
| **ค้นหาคอร์ด** | ดึงคอร์ดกับเนื้อร้องจาก [busk.town](https://busk.town) ทีละเพลงตามที่คุณกด |
| **เปลี่ยนคีย์** | 14 คีย์ และสลับเป็นชุดคอร์ดง่ายได้ |
| **จัดรูปแบบ ChordPro** | แทรกคอร์ดในวงเล็บก้ามปู รวมท่อนดนตรีให้อยู่บรรทัดเดียว ครอบวงเล็บให้ท่อนซ้ำ |
| **ส่งออก `.sbp`** | เขียนไฟล์ ZIP ตามรูปแบบที่ SongBookPro เขียนเอง พร้อม MD5 ครบถ้วน |
| **บันทึก `.txt`** | ไฟล์ ChordPro ธรรมดา เอาไปใช้กับโปรแกรมอื่นได้ |
| **ช่วยด้วย AI** | สร้างพร้อมท์ให้คัดลอกไปวางในแชท หรือใส่ API key แล้วให้แอปส่งเอง |
| **ไทย / English** | สลับภาษาได้ทั้งแอป |

ดึง `{title}` `{artist}` `{tempo}` `{time}` จากเนื้อ ChordPro ไปใส่ในไฟล์ `.sbp` ให้อัตโนมัติ

เรื่องที่พิถีพิถันเป็นพิเศษคือ **การวางคอร์ดบนคำไทย** — สระบนล่างกับวรรณยุกต์ไม่กินความกว้าง
ถ้านับเป็นจำนวนตัวอักษรตรงๆ คอร์ดจะเลื่อนผิดทั้งเพลง แอปนี้นับตามความกว้างที่ตาเห็น
และไม่วางคอร์ดคั่นกลางระหว่างพยัญชนะกับสระของมัน

## ข้อมูลของคุณอยู่ที่ไหน · Privacy

ทุกอย่างทำงานในเบราว์เซอร์ของคุณ **ไม่มีการอัปโหลดไฟล์ไปที่ไหน** ไม่มีตัวนับสถิติ
ไม่มีสคริปต์จากภายนอก ไม่มีเซิร์ฟเวอร์ของเราเพราะไม่มีเซิร์ฟเวอร์

แอปยิงออกนอกเครื่องแค่สองที่เท่านั้น

- **busk.town** ตอนกด *ค้นหาคอร์ด* — ขอข้อมูลเพลงเดียวที่คุณพิมพ์ชื่อ
- **เจ้าของ API ที่คุณเลือก** ตอนกด *ส่งให้ AI ทำเลย* — ด้วยคีย์ของคุณเอง
  ซึ่งเก็บไว้ในเบราว์เซอร์เครื่องนี้เท่านั้น

ถ้าไม่อยากให้ส่งอะไรออกเลย วางใบคอร์ดเองแล้วใช้ปุ่ม **จัดรูปแบบ** อย่างเดียวก็พอ
แบบนั้นเปิดจากไฟล์ในเครื่องแบบออฟไลน์ได้ด้วย

## เรื่องลิขสิทธิ์ · About lyrics

แอปนี้ **ไม่ได้สร้างเนื้อเพลงขึ้นเอง** และ AI ก็จะไม่พิมพ์เนื้อเพลงที่มีลิขสิทธิ์ออกมา
สิ่งที่มันทำคือดึงหน้าที่เปิดอ่านได้อยู่แล้วมาจัดรูปแบบใหม่ หรือจัดรูปแบบใบคอร์ดที่คุณมีอยู่

เนื้อเพลงและใบคอร์ดที่ได้มายังเป็นลิขสิทธิ์ของเจ้าของเช่นเดิม
ควรใช้เพื่อเล่นเองหรือเรียนเอง ไม่ใช่เอาไปจำหน่ายต่อ

ตัวแอปดึงทีละเพลงตามที่ผู้ใช้กดเท่านั้น **ไม่มีโหมดไล่ดูดทั้งเว็บ** และติดลิงก์กลับไปที่
หน้าต้นทางทั้งบนหน้าจอและในไฟล์ที่ส่งออกทุกไฟล์

## ทดสอบ · Tests

```bash
node test/test.mjs
```

ไม่ต้องติดตั้ง dependency อะไร ใช้ Node เปล่าๆ · ชุดทดสอบอ่านโค้ดจาก `index.html`
ตัวจริง ไม่ใช่สำเนา และไม่ยิงเน็ตเลย (ใช้ของปลอมแทน) · ครอบคลุม MD5 (เทียบกับเวกเตอร์
ใน RFC 1321), CRC32, โครงไฟล์ `.sbp`, การวางคอร์ดบนคำไทย, ตัวจัดรูปแบบ,
การแปลภาษา และการต่อ API
